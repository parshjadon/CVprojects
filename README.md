# Computer Vision Projects

Single Streamlit deployment for the Computer Vision module projects.

## Included pages

- Module 2: Camera Calibration and Object Measurement
- Module 3: Spatial vs Fourier Image Blurring
- Module 4: Human Boundary Extraction
- Assignment 6: Optical Flow and Structure from Motion

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy on Streamlit Community Cloud

Use this repository as the source and set the main file path to:

```text
app.py
```
